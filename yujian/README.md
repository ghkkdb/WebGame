# 御剑十分钟 · 首版

直接使用 Chrome 或 Edge 打开上一级目录中的 **御剑十分钟_V1.html** 即可游玩。最终文件包含引擎、样式、脚本和生成资源，不需要联网或安装依赖。

## 已实现

- 三名可选侠客：沈孤鸿（剑）、叶无痕（双匕）、苏照晚（药伞）。
- 程序生成的雨夜山庄、竹林、建筑、石板路、灯笼和雨水。
- 自动攻击、鼠标指向、轻功闪避、主动绝技。
- 专属兵器、每人两门专属武学、六门通用武学、六门内功。
- 升级三选一、有限重选、技能槽上限和六条融合路线。
- 三处可选江湖奇遇；六种普通敌人、两次精英战和黑伞客首领战。
- 十分钟战斗计时、暂停、胜利／落败／超时结算、本地累计战绩。
- 窄屏布局、触屏摇杆与按钮。触屏真机操作手感尚未验证。

## 操作

| 操作 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标指向 | 主要攻击方向；鼠标离开画面后恢复自动索敌 |
| 空格 | 轻功，可储备两次 |
| Q | 主动绝技，默认冷却约22秒 |
| B | 查看武学配方，暂停时间 |
| E | 与附近奇遇人物交谈；停步片刻也会触发 |
| ESC | 暂停或继续 |
| 1 / 2 / 3 | 升级界面快速选择 |

靠近青色修为晶石即可拾取。红橙色地面区域是敌方攻击预警。

## 融合绝学

条件：本命兵器六重、对应专属武学三重、对应通用武学三重、一次悟道机会。第四分钟和第七分钟各出现一名执令剑使，击败后获得悟道机会。每局只能融合一次，融合后绝技立即就绪。

| 侠客 | 专属武学 | 通用武学 | 绝学 |
| --- | --- | --- | --- |
| 沈孤鸿 | 御剑式 | 引雷诀 | 九霄雷剑 |
| 沈孤鸿 | 回锋式 | 寒潭劲 | 霜河剑域 |
| 叶无痕 | 影袭 | 飞叶术 | 千叶无踪 |
| 叶无痕 | 断脉 | 流火诀 | 焚心断脉 |
| 苏照晚 | 药雾 | 流火诀 | 百草焚香 |
| 苏照晚 | 花针 | 寒潭劲 | 雪魄金针 |

黑伞客在八分三十秒登场。十分钟之前击败首领即可突围，倒下或超时结束本局。升级和菜单不占战斗时间。

## 源码与构建

- `index.html`：页面结构。
- `style.css`：菜单、战斗界面、响应式样式。
- `game.js`：场景生成、角色、战斗、武学、流程与界面。
- `three.local.js`：从用户提供的 HTML 中提取的 Three.js r180 引擎。
- `build.mjs`：将上述文件合成为单个 HTML。
- `serve.mjs`：仅供开发使用的本地预览服务器。
- `THIRD_PARTY_LICENSES.txt`：Three.js 的许可声明。

在本目录的上一级运行：

```powershell
node yujian/build.mjs
node yujian/serve.mjs
```

开发预览地址：`http://127.0.0.1:4173/`。服务器只监听本机。

## 验证

本地服务器启动后，打开 `http://127.0.0.1:4173/?test=1`，点击“运行开发自检”。普通入口不会显示开发面板。

自检覆盖三名角色的启动、轻功、主动绝技、升级、技能槽限制，六条融合路线，建筑绕障寻路，首领阶段模拟与结算，共50项检查；首领阶段使用强化配置和免伤，以验证流程与运行稳定性。另有前三分钟自动拾取修为的成长检查。记录见 `验证记录.txt`。

浏览器运行验证通过本地 HTTP 完成。内置浏览器安全策略禁止 `file:` 协议，因此文件直接打开方式未在内置浏览器中实测；已检查交付 HTML 的两个内联脚本语法及零远程素材依赖。

当前为可玩原型，美术采用程序化风格，正常难度、长期流派平衡和触屏手感仍需结合试玩反馈迭代。当前保存累计战绩与声音偏好，不保存进行中的战斗。
