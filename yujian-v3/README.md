# 御剑十分钟 · 第三卷：像素江湖

交付文件：[御剑十分钟_V3_像素江湖.html](../御剑十分钟_V3_像素江湖.html)。使用 Chrome 或 Edge 打开，约11.4 MB，代码、角色精灵和场景素材均已内联，游戏运行无需联网。V1、V2 和原始 FPS 文件保留。

## 本次实装

本次新增行旅玩法：3种开局志向、融合路线追踪与领悟推荐、9件机缘信物（第3/6/9波前择取）、3类限时悬赏、3种波次敌情、连斩增益、奇遇方向引导、战后复盘与跨局见闻收藏。规则与数值见 [行旅与可玩性优化说明.md](行旅与可玩性优化说明.md)。普通入口直接选择侠客后启程即可体验，无需开启开发模式。

实战画面使用 Canvas 2D：屏幕原生分辨率画布、原始透明像素精灵与最近邻采样，保留图集细节，没有使用三维画面像素滤镜，也没有把概念稿作为不可交互的游戏背景。

- 三名侠客各有六帧跑步和六帧出招，移动中上下身分别播放动作；三类基础追兵复用原四帧行走。步频跟随真实移动距离，左右朝向通过水平翻转表现。精英和其他兵种复用基础精灵与不同缩放，当前还没有完整八方向动画。
- 按确认稿的配色和题材接入青瓦茶舍、竹林、花树、苔石、灯笼、古碑、宝箱、药摊、古祠、货郎与试剑木人。
- 场景物件与角色按脚底纵坐标排序；人物在高物件后方时，遮挡物变淡；建筑保留与底部占地对应的碰撞。
- 程序绘制青石古道、草地、浅塘、像素雨线和飘花；青白剑气、紫色残影、追踪蝴蝶、落剑、落雷、伤害数字与命中碎光均实时绘制。
- 首页改为像素角色选择卡，HUD、商店和领悟界面统一为青绿底、米白字与暖金硬边框，武学栏使用像素图标。

生成图是素材来源；单张概念稿的构图不会在随机地图中逐像素复现。实际画面见本目录的实战预览。

## 玩法与操作

保留十波围攻，每波60秒战斗时间；自动出招与索敌；波末统一领悟，随后进入购买、保留、刷新商品的商店；六个武学槽、装备属性叠加、六条融合路线。第4、7波出现精英，第10波出现黑伞客。

地图沿四方持续生成，维持附近九个区块并回收远处区块。每局随机种子，同局重访内容一致；角色无坐标钳制或回绕。六类奇遇可获得武学、器物、属性、铜钱或悟道机会，同一处每局仅领取一次。

| 操作 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 按住鼠标左键 | 定向瞄准；松开自动索敌 |
| 空格 | 轻功，两次储备 |
| E | 门派身法，剑客可连续三段衔接 |
| Q | 绝技 |
| F / 点击奇遇提示 | 附近奇遇交互 |
| B | 武学融合配方 |
| ESC | 暂停与继续 |
| 1 / 2 / 3 | 波末领悟选择 |

藏峰山持剑发出穿透剑气，E三段踏风出剑，Q霜天剑雨。夜行司持双匕投掷飞镖，E退步隐匿与飞镖破印，Q多轮镖阵。百草汀撑伞唤蝶，E回复花庭，Q伞面展开与蝶群领域；溢出回复转护盾。商店、领悟、奇遇选择和暂停不计战斗时间。

## 构建与预览

从项目根目录运行：

```powershell
node yujian-v3/assemble.mjs
node yujian-v3/serve.mjs
```

预览地址为 `http://127.0.0.1:4173/`。`?test=1` 显示开发验证、角色实战和补给预览面板，开发入口使用独立的战绩存储。实战预览会强化角色并提供临时免伤，普通入口没有这些设置。

- `legacy-core.js`：第二版逻辑的独立快照，作为数据和共用武学界面的组合基底，无需依赖第二版目录构建。
- `world.js`：像素地图区块、对象分布、碰撞与共享寻路。
- `pixel.js`：透明图集切片、绘制缓存、深度排序、坐标投影、角色行走、技能和天气绘制。
- `pixel.css`：像素版界面样式。
- `combat.js`、`lifecycle.js`、`interface.js`：战斗、波次、奇遇、商店与输入，组合时由 `assemble.mjs` 替换原有三维绘制部分。
- `actors.js`：复用特效的生命周期和战斗对象，组合时简化角色对象并补入二维绘制数据。
- `three.local.js`：既有 Three.js r180，仅保留数学与战斗对象兼容，本版不创建 WebGLRenderer。许可见 `THIRD_PARTY_LICENSES.txt`。
- `assets/`：角色、场景和三侠动作图集；生成方式与完整提示词见 `美术资产说明.md`、`人物动作素材提示词.txt`。

## 验证

浏览器内293项检查全部通过，完整结果见 `验证记录.txt`。保留原216项角色、武学、特效、地图、图标与波次回归，增加77项行旅机制和完整十波检查，覆盖信物实际收益、奖励去重、暂时增益清理、触屏按钮接入、路线更换、收藏持久化与结算返回。完整十波模拟通过9次补给、3次信物选择、目标融合和首领结算；该模拟使用免伤验证流程。普通入口另实测开局志向/路线选择、移动、Q和暂停，浏览器无错误或警告。

自动成长与首领模拟使用免伤验证流程，不能作为正常难度平衡或通关证明。移动端提供布局与触屏控件，尚未进行真机手感测试。浏览器运行检查采用本地 HTTP；内置浏览器限制 `file:` 协议，因此文件双击打开未在该浏览器内实测。单文件已经过脚本语法与零远程资源引用检查。

行旅实现位于 `journey.js`、`journey.css`、`journey-qa.js`；新实机截图为 `行旅优化_开局.jpg`、`行旅优化_普通实战.jpg`、`行旅优化_茶亭.jpg` 和 `行旅优化_见闻.jpg`。见闻使用浏览器本地存储，和旧战绩分开保存；不包含局中续存或云同步。

## 武学与装备图标更新

45项正式图标已统一接入领悟、商店、奇遇、融合配方和技能栏，另有6项奇遇奖励图标。按 B 可查看随身器物及叠加数量，并进入“武学与器物图鉴”。对应表和实现说明见 `图标适配说明.md`。

## 清晰度与门派攻击更新

画布现按屏幕像素绘制，不再将角色压成48像素后放大。三门派的剑气、飞镖、蝴蝶分别实现轮廓、轨迹、身法、绝技和命中反馈；专属武学、融合绝学与图标同步适配。技术说明与实机截图位置见 `清晰度与门派攻击说明.md`。

## 人物动作更新

新增36帧三侠跑步与出招素材，接入实际位移驱动的步态、移动出招分层、朝向保护、普攻短前摇、轻功姿态残影与落地缓冲。`motion.js` 管理人物动作；`motion-qa.js` 提供25项动作检查及开发面板的“动作预览”。细节、素材提示词和限制见 `人物动作优化说明.md`，浏览器动作实录见 `人物动作_预览.gif`。

## 技能特效更新

`skill-effects.js` 是当前构建使用的特效模块，替代旧 `school-visuals.js`。更新三门派的普攻、E/Q、六门专属武学、六门通用武学及六条融合路线的视觉差异；特效按地面和人物上层分别绘制，并限制短时效果总数。新增29项特效检查。范围、实现与验证限制见 `技能特效优化说明.md`，演武实录见 `技能特效_三门派.gif`。

## 通用武学与融合绝学深化

`arts-effects.js` 为六门通用武学补充冷却末段蓄势、独立释放/命中/持续区域，为六条融合路线补充独立阵形、残影、符印、烟莲和晶蝶演出。真实连锁伤害、减速、灼烧、回复与护盾触发对应反馈，伤害数值、冷却和范围沿用既有规则。

`arts-qa.js` 新增35项验证及十二门武学演武入口。开发入口可切换“定格预览”观察技能高峰；普通开局会重置演武冻结状态。实现和验证范围见 `通用与融合特效说明.md`，逐项截图见 `武学特效预览/`，六式对照图为 `通用武学_六式对照.jpg`、`融合绝学_六式对照.jpg`。定格图由真实游戏逻辑推进到指定时刻后捕获，拼图使用 `compose-art-previews.ps1`（需本机 ffmpeg）。
