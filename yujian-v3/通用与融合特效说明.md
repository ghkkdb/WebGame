# 通用武学与融合绝学特效深化

本轮在原有像素特效基础上，为六门通用武学及六条融合路线加入独立演出。交付文件仍为根目录《御剑十分钟_V3_像素江湖.html》，修改前版本保留为《御剑十分钟_V3_通用融合优化前备份.html》。没有新增远程资源或修改伤害、范围、冷却、升级条件与融合配方。

## 六门通用武学

| 武学 | 释放与持续表现 | 命中表现 |
| --- | --- | --- |
| 引雷诀 | 蓄雷光点、分叉落雷、相邻落点间的电弧、电痕 | 雷光与电裂纹 |
| 流火诀 | 火种蓄势、六向火舌爆开、地面焦痕与持续余烬 | 短促火焰，灼区随既有伤害节奏脉动 |
| 寒潭劲 | 寒气聚集、向外生长的分叉冰纹、边缘冰晶 | 减速敌人脚下有细小霜晶 |
| 飞叶术 | 旋叶蓄势、扇形放叶、带叶脉的穿透飞叶与短尾迹 | 命中散叶 |
| 回风掌 | 聚气环收拢、向外推出的分层掌风、离地气旋与卷叶 | 受击处的压力风弧，沿用实际击退 |
| 落英阵 | 花瓣蓄势、五瓣花形展开、向外绽放的花瓣、持续阵花 | 飘散碎瓣 |

蓄势发生在实际技能计时器结束前最多0.18秒，每个周期只触发一次；不会推迟伤害或更改技能冷却。需要目标的技能在实际释放时仍按原有索敌规则选择目标。火区与落英阵继续使用原来的持续伤害时机，不增加新的爆炸伤害。

## 六条融合路线

| 绝学 | 独立演出 | 与真实效果的对应 |
| --- | --- | --- |
| 九霄雷剑 | 六向电阵、悬剑引电、命中电芒与锯齿连锁电弧 | 连锁电弧指向实际受到连锁伤害的目标 |
| 霜河剑域 | 六枝霜河裂纹、冰晶剑柱、专属寒剑落雨 | 命中后的减速脚霜，保留原来的减速规则 |
| 千叶无踪 | 叶刃环阵、左右残影、缠绕飞镖的双叶与命中散叶 | 残影和飞叶为演出，不额外增加攻击次数 |
| 焚心断脉 | 三枚断脉符印、环绕炎符、命中烙印、灼烧余烬 | 敌人已有灼烧时才显示持续余烬 |
| 百草焚香 | 八瓣烟莲、外缘香炉、上升香烟、金蝶与归流光点 | 归流光点只在生命或护盾实际增加后触发 |
| 雪魄灵蝶 | 六枝雪纹、晶蝶环舞、晶化蝶翼与冰晶护体 | 命中触发原有护盾收益时显示护体效果 |

融合绝学使用独立演出层级，替代基础剑阵/镖阵的重复装饰，减少多层同类阵纹堆叠。持续焚香场与冰蝶花庭分别有香炉/烟气及雪枝/晶体边缘。角色、技能效果与敌方红色预警的绘制层次沿用上一版。

## 实现与验证

`arts-effects.js` 管理通用释放、命中、状态、六种融合演出与回流；`arts-qa.js` 验证实际技能计时、释放伤害、圆形范围、六种融合绘制差异、真实连锁/减速/灼烧/回复/护盾、暂停与清理。`skill-effects.js` 提供共享像素绘制和128个短时特效预算。

仅开发入口 `?test=1` 增加十二门武学的演武按钮和“定格预览”开关，普通入口不显示。定格模式将真实游戏逻辑推进至招式高峰，再冻结战斗与特效更新；普通开局自动重置冻结状态。演武使用强化角色、高血量静止靶敌及预置融合，供逐项观察特效；不作为正常难度、低端设备或移动真机性能测试。

216项回归检查全部通过，其中本轮新增35项。另通过普通入口实际测试了移动、E/Q与暂停，浏览器没有游戏脚本错误或警告。完整记录见 `验证记录.txt`。

十二门武学的定格实机截图位于 `武学特效预览/`，对照图为 `通用武学_六式对照.jpg` 与 `融合绝学_六式对照.jpg`。截图保留招式名称和周边场景，便于比较；拼图脚本为 `compose-art-previews.ps1`，需要本机已有的 ffmpeg。
