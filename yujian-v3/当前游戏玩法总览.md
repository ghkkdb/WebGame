# 御剑十分钟 · 当前游戏玩法总览

本文依据当前实装代码整理，描述普通游戏入口的规则。开发预览中的高境界、强化技能、铜钱和免伤不属于正常开局。

《御剑十分钟》是一款二维像素武侠生存构筑游戏：选择侠客，在持续延伸的地图中移动、自动攻击和寻找奇遇；通过战斗修为、波末领悟与商店装备形成流派，最终在第十波击败黑伞客。

地图可向四方持续延伸，单局目标仍是十波突围。每波60秒战斗计时，总计最多约10分钟；升级选择、补给、奇遇选择与暂停不计入战斗时间。

## 一局流程

1. 选择一名侠客。三人全部开放，角色与本命兵器绑定。
2. 选择破阵客、云游人或守心者志向，再选一条融合目标。开局拥有1重本命兵器、目标所需通用武学1重、可用的E身法与Q绝技、两次轻功储备、20铜钱；志向提供本局特色收益。
3. 在每波60秒中移动、躲避、自动攻击，拾取修为、获得铜钱，沿地图寻找奇遇。
4. 修为足够时境界提升，积累领悟次数；战斗中不会立即弹出升级窗口。
5. 波末自动收取遗留修为、清理当波敌人与弹体，恢复12生命，并获得额外铜钱；依次处理待领悟次数，每次通常从3项中选择1项。
6. 进入四格补给商店，购买武学或装备、保留商品、付费刷新。钱可以留下，用于后续波次。
7. 带着当前位置、武学、装备和属性进入下一波。第3、6、9波前额外进行机缘信物三选一；第四波、第七波出现精英剑使。普通波次会出现疾行、重甲或箭雨敌情。
8. 满足融合条件后，按B进入秘籍页，选择参悟一门融合绝学。
9. 第十波出现黑伞客；在这波结束前击败即胜利。生命归零，或总战斗计时达到600秒仍未击败首领，则失败。
10. 结算展示波次、破敌、距离、奇遇、构筑、连斩、悬赏、信物和融合差距，保存见闻收藏，随后可重选角色或重新立志开局。暂停中主动结束也会进入复盘。

第一至第九波以生存到时间结束为过关条件，不要求击杀所有敌人。途中货郎不会推进波次。首领被击败后直接结算，当前没有通关后继续探索模式。

## 技能分类、获取与槽位

- 本命兵器：每人固定一种，开局1重，最高6重；通过领悟或商店强化。每升1重增加30%基础兵器伤害，三重、六重额外增加一道攻击。
- 门派武学：每人两门，开局尚未习得，最高3重；只进入本角色的候选池，通过领悟、商店或悟剑石获得。习得后自动施展。
- 江湖武学：六门供全部角色选择，最高3重；通过领悟或商店获得，习得后自动施展，每局最多携带三门。
- 内功心法：六门供全部角色选择，最高3重；通过波末领悟获得，当前商店不出售内功，每局最多修习三门。
- E与Q：各门派固定主动招式，不占自动武学槽。
- 融合绝学：每门派两条路线，每局限参悟一门，用于强化现有构筑与Q表现。

六格自动武学为：1格本命兵器＋2格本门专属武学＋3格江湖武学。三门内功独立计算，E/Q也独立计算。装备不占武学槽，当前没有出售或替换已学武学的功能。

同一武学再次获得会升一重，满重后不再进入候选池。每局开始有3次重阅领悟选项的机会；商店刷新使用铜钱，两套次数分别计算。悟剑石在门派武学满重后可以补充重阅机会。

## 融合条件与六条路线

融合需要同时满足：本角色本命兵器六重、配方对应专属武学三重、对应江湖武学三重、至少一次悟道机会，并且本局尚未参悟其他绝学。按B查看条件并手动参悟，消耗一次悟道机会；材料武学与兵器保留。

悟道机会来自击败第四波、第七波的精英剑使，或接受并完成试剑奇遇。撑过精英所在波次不会自动获得悟道机会。

## 敌人与节奏

第一波以持刀追兵为主；第二波加入弓手，第三波加入盾卫，第四波加入火药客和精英，第五波加入夜行刺客，第六波加入长枪护院，第七波再次出现精英，第十波出现黑伞客。后续波次持续混合此前敌人，数量压力与普通敌人属性逐步提高。

黑伞客具备扇形弹幕、地面范围预警、环形范围攻击和召来刺客等手段，生命降低后出招更快。轻功、E/Q保护、击退、减速与回复用于处理围攻。

## 成长闭环与当前范围

即时循环：移动躲避 → 攻击命中 → 击退追兵 → 获得修为与铜钱 → 继续移动和探索。

波次循环：60秒围攻 → 波末领悟 → 商店整备 → 武学与装备强化 → 迎接更强围攻。

流派循环：选择本门特色 → 搭配三门江湖武学和三门内功 → 装备补齐伤害或生存 → 击败精英取得悟道机会 → 参悟一门绝学 → 挑战黑伞客。

重玩循环：结算查看构筑与战绩 → 换角色、路线或装备思路 → 新种子重新开局。

局外保存原有战绩和声音设置，并记录侠客足迹、融合绝学、机缘信物、奇遇类型、6枚见闻印记与最近5次行旅。武学、装备、铜钱、志向、信物效果和悟道机会均为局内成长，重新开局重置；没有永久属性成长、角色解锁树或局中续存。离开页面会自动暂停，刷新页面不会保存当前战局。

每波前45秒可完成清剿、探索或无伤悬赏，奖励铜钱与重阅；每15连斩可获得5秒伤害加成。路线推荐与实时进度帮助构筑成型，随机信物和敌情增加局内决策，见闻收藏与战后复盘形成跨局目标。完整规则与九件信物数值见《行旅与可玩性优化说明.md》。数值仍需随正常试玩调整。
