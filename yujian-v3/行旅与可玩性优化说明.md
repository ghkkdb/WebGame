# 行旅与可玩性优化

本次围绕每局决策、构筑成型、战斗节奏、探索目的和跨局记录扩充内容。交付仍为根目录的《御剑十分钟_V3_像素江湖.html》，直接替换现有版本；更新前文件保存在《御剑十分钟_V3_可玩性优化前备份.html》。三角色、像素画面、无边界地图、六条融合与十波框架继续沿用。

## 开局：志向与目标

选角后进入行前选择。三个志向全部开放，只对本局生效：

| 志向 | 初始变化 | 持续收益 |
| --- | --- | --- |
| 破阵客 | 伤害 +12%，生命上限 -8 | 每破敌20人回复6生命 |
| 云游人 | 移速 +8%，拾取距离 +1 | 每处已完成奇遇额外12铜钱 |
| 守心者 | 生命上限 +15 | 开局及每波开始获得12护盾，上限50 |

每位侠客可以选择本门两条融合路线之一，开局获得对应通用武学一重。领悟的三项中，只要仍存在可修习的目标材料，就至少包含一项；仍需玩家自己选择，仍受槽位和满重限制。符合目标的秘籍在领悟与商店中标记。B秘籍页可更换目标；若另一路的通用武学未学且通用槽已满，则不能换到无法成型的路线。不会删除玩家已经选择的技能，也不保证每次商店都出现所需秘籍。

## 波间：九件机缘信物

第3、6、9波开始前分别进入茶亭，从尚未持有的信物中随机抽3件，选1件。每局最多3件，选取期间暂停，支持点击或1/2/3。信物不占武学、装备槽；B秘籍可查看已取得信物及完整效果。

| 信物 | 本局效果 |
| --- | --- |
| 踏风铃 | 空格轻功成功后在起点释放回风掌一重，内部冷却3秒 |
| 追魂签 | 每破敌8人，E冷却减少1秒、Q减少2秒，最低为0 |
| 两仪佩 | 对处于减速或灼烧中的敌人，伤害提高25%；两种状态同时存在仍只加25% |
| 不动印 | 轻功成功获得6护盾，内部冷却5秒，盾上限50 |
| 回生莲 | 实际损失生命后，3秒内按每秒3点回复9生命，内部冷却12秒 |
| 惊雷木 | Q成功释放后追加引雷诀二重；冷却中按Q不会触发 |
| 四方钱 | 立即35铜钱；每完成奇遇额外15铜钱，可与云游人叠加 |
| 问道盘 | 目标的一项可修武学升一重，获得1悟道机会和1重阅；无可修材料则改给25铜钱 |
| 孤锋石 | 立即增加10生命上限并回复10；低于一半生命时伤害提高30% |

这些效果与现有实际战斗函数连接，复用已经优化的像素招式。例如踏风铃能形成“轻功脱身—掌风击退”，两仪佩适合冰系、灼烧路线，惊雷木可以与门派绝技叠加。没有另造独立于实际伤害的假命中。

## 战斗：敌情、悬赏与连斩

第2至9波按地图种子抽取一种敌情，补给页提前展示，HUD持续显示：

- 疾行围猎：普通近战追兵移速提高15%，弓手、火药客、精英、首领不享受加速。
- 重甲压阵：普通追兵生命提高25%、移速降低12%，精英和首领不受影响。
- 箭雨封路：每12秒追加1名弓手，仍受既有敌人池上限限制。

第1波保持入门节奏，第10波回到首领决战，不叠加上述普通敌情。敌人原有技能与红色预警保持。

每波前45秒有一份可选悬赏，按清剿、踏遍、从容三类轮换：

- 清剿追兵：击败 `12 + 波数 × 3` 名敌人。
- 踏遍古道：实际移动95丈，轻功/身法产生的有效位移计入。
- 从容应敌：连续18秒不损失生命；护盾吸收、无敌与闪避不算损失生命。

完成立即获得 `18 + 波数 × 2` 铜钱与1次重阅。失败不扣钱、不结束游戏。每波只能领一次，暂停和菜单不计时。

3.5秒内继续击杀可延续连斩，每15连斩获得5秒“剑意昂扬”，伤害提高20%。断连不取消已经取得的增益，但到时会结束。增益不无限叠层；与两仪佩、孤锋石按加成之和作用于伤害。

## 探索和界面

左侧行旅HUD显示敌情、悬赏进度、剩余时间、连斩/剑意状态、目标融合材料与悟道机会。点击路线可打开秘籍。下方显示当前加载区块内最近未完成奇遇的方向与直线距离；到达后仍需绕过建筑并按F互动。小地图保留，地图持续生成和回收。

开局选择、领悟、商店、秘籍、暂停与帮助已接入新规则。原奇遇里容易误解的“永久”改为“本局”。触屏轻功/绝技与键盘使用同一套信物逻辑；尚未完成移动设备真机手感测试。

## 结算与见闻

死亡、超时、通关，或在暂停中选择“结束此局，查看复盘”，都会记录本局。结果页新增最高连斩、完成悬赏、信物组合、新获得印记和目标融合尚缺的材料；再来一局会重新选择志向。收藏页可从首页、秘籍或结果页进入。

跨局记录包括：3位侠客足迹、6门融合绝学、9件信物、6类奇遇、6枚见闻印记、行旅/破局次数、最高抵达波次、累计完成悬赏、最近5次结算。收藏不提供永久战斗属性。

印记条件：完成一局、击败首领、单局3处奇遇、30连斩、5次悬赏、修成融合。发现条目会在获得时保存；完整战绩在结算时保存。数据使用独立版本键，保留旧版战绩。开发入口使用独立存储，回归测试还会还原测试前记录。存储损坏时使用空记录；浏览器禁用存储时继续游戏，并在见闻/结算中说明只能临时保留。

刷新页面仍不会恢复未完成战局。收藏保存在当前浏览器和打开来源，不是云存档；不同浏览器、HTTP预览和直接文件打开可能使用不同存储空间。
