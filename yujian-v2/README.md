# 御剑十分钟 · 第二卷：江湖无界

主文件：上一级的 **御剑十分钟_V2.html**。使用 Chrome 或 Edge 打开，全部引擎、立绘、界面和游戏代码已内联，运行无需联网。第一版保留。

## 本版玩法

- 自动攻击与索敌，WASD 或方向键移动；按住鼠标左键可定向瞄准。
- 十波围攻，每波六十秒。战斗中积累领悟次数，波末统一选择武学，随后进入补给商店。
- 商店可购买秘籍、叠加装备、保留商品、花铜钱刷新；部分器物用生命上限或移速交换更高输出。
- 地图向四方动态生成，远离的区块回收。角色不会被限制在旧场景坐标内，也不会绕回原点。
- 每局生成新的地图种子；同一局重访时保持环境与奇遇的一致性。
- 沿途有悟剑石、药庐、行囊、古碑、试剑挑战、游方货郎六类奇遇，获得武学、器物、属性、铜钱或悟道机会。
- 同一处奇遇每局只能领取一次。第四波、第七波出现精英，第十波出现黑伞客。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标左键按住 | 定向出招；松开后自动索敌 |
| 空格 | 轻功，两次储备 |
| E | 门派身法，短冷却主动招式 |
| Q | 绝技，基础冷却24秒 |
| F | 与附近奇遇交互，也可点击提示 |
| B | 查看武学与融合配方 |
| ESC | 暂停／继续 |
| 1 / 2 / 3 | 波末领悟快速选择 |

升级选择、商店、奇遇选项和暂停不占战斗时间。移动端提供摇杆与技能按钮，触屏真机手感尚未验证。

## 三名侠客

**沈孤鸿：剑风与连招。** 自动三段连斩，第三式强化剑气；远距离自动补出剑气。E「追风三叠」可在短时间内连续三次位移斩击。Q「霜天剑雨」在周围多次落剑。两条融合路线：九霄雷剑、霜河剑域。

**叶无痕：隐匿、香印与背袭。** 双刃连斩附加香印，轻功后提高暴击。E「月下藏锋」切到目标背后，消耗印记爆发。Q「月下千刃」连续追斩附近目标。两条融合路线：千叶无踪、焚心断脉。

**苏照晚：蝶群、回复与花庭。** 自动放出追踪蝶群，溢出治疗转为护盾。E「花汀蝶梦」布下持续伤敌、回复自身的花庭。Q「梦泽千蝶」展开大范围领域并释放蝶群。两条融合路线：百草焚香、雪魄金针。

融合条件：本命兵器六重，对应专属与通用武学各三重，消耗一次悟道机会。每局修成一门。

## 画面与手感调整

- 原创三角色立绘；重建成人比例的三维人物、分段手臂和腿部、衣摆、发带、长剑、双匕与油纸伞。
- 月夜青黛色调、石板纹理与裂痕、竹叶、花树、荷塘、屋檐和暖色灯笼。
- 斩击弧面、追踪蝶群、剑雨、落雷、命中闪白、伤害数字、碎光与死亡反馈。
- 移动加减速、平滑转身和镜头跟随；短暂命中停顿、轻微镜头震动；减少动态效果偏好会抑制震动。
- 半浮点画面缓冲、低分辨率泛光、色调映射；不支持对应扩展时使用基础渲染。
- 同材质场景合批、追兵实例化、局部共享寻路流场、区块与奇遇资源回收。

这是可玩原型。人物采用程序化风格，立绘细节与实战模型的精度存在差距；数值和长期流派平衡仍需实际试玩反馈。

## 开发与验证

从项目根目录运行：

```powershell
node yujian-v2/rework.mjs
node yujian-v2/build.mjs
node yujian-v2/serve.mjs
```

本地预览：`http://127.0.0.1:4173/`。添加 `?test=1` 可显示开发验证、角色实战和商店预览按钮。普通入口不显示开发面板。

`base.js` 保留角色数据与共用秘籍界面的基底；`rework.mjs` 组合 `world.js`、`actors.js`、`combat.js`、`lifecycle.js`、`interface.js`、`post.js`、`audio.js`、`guide.js`、`qa.js` 为 `game.js`；`build.mjs` 再合成单文件。

验证记录见 `验证记录.txt`，62项机制检查已通过。自动测试包含战斗中升级不打断、波末领悟、购买与扣款、保留商品、波次衔接、远处移动、区块回收、奇遇重访、六条融合路线等。首领和成长模拟使用免伤，以验证流程，不作为正常难度通关证明。另通过实际键盘按键检查移动、身法和绝技。

运行检查使用本地 HTTP。内置预览器不允许 `file:` 协议，因此直接打开文件的方式未在该预览器中实测；已检查单文件脚本语法和零远程素材依赖。
